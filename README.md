# QR Ant Colony · 二维码蚁穴

一个把**真实可扫描二维码**直接变成蚂蚁地下巢穴的网页游戏原型。

> 你穿越成了一只蚂蚁。这个二维码，就是你的整个世界。

## 当前玩法

### 第 1 关：第一顿饭

- 不限时间，作为新手教学关。
- 初始人口 3，只需要学习移动、探索、发现食物、回巢报信和运输。
- 玩家实际走回蚁穴的路线会成为信息素运输线，工蚁会沿这条路线搬运。
- 每储备 2 份食物会孵化新的蚂蚁；人口达到 10 即通关。
- 🍩 甜甜圈：2 份普通食物。
- 🧁 杯子蛋糕：3 份食物，并提供 15 秒移动加速。
- 🍰 草莓蛋糕：5 份食物，并额外孵化 1 只蚂蚁。
- 「扫码模式」会隐藏所有游戏覆盖层，显示标准黑白二维码，方便手机直接扫码验证。

### 游戏性优化：路线、分工与进化

当前版本把三个核心系统做成了跨关卡机制：

- **路线效率**：玩家发现食物或泥土后，实际走回蚁穴的路线会被记录。系统会把这条路线与最短路径比较，得到 35%–100% 的路线效率；路线越短，工蚁搬运越快。
- **路线反馈**：食物运输线会按效率变色，绿色代表高效，黄色代表一般，红色代表绕路较多。
- **蚁群专精**：通关后可以选择发展方向，例如信息素专家、工程蚁训练、预备兵蚁等；它们不会让第二关少掉工蚁，10只工蚁仍会全部参与搬泥，只是部分蚂蚁获得额外专长。
- **通关三选一**：第一关和第二关通关后都会弹出一次进化选择，且效果会带到后续关卡。
- **守卫蚁**：选择兵蚁相关进化后，第三关会出现自动驻守蚁穴的守卫蚁，玩家负责前线战斗，守卫蚁负责最后一道防线。
- **战斗分支**：第二次进化可以选择提高咬击伤害、增加自动守卫，或提高蚁穴生命。

这样前面关卡学到的“探索 → 报信 → 留下路线”不会被后面的玩法抛弃，而会继续影响施工和防守效率。

## 第 2 关：暴雨来了

- 90 秒倒计时，地图随机生成 2 个可达入口与 3 处可达泥堆。
- 玩法沿用第一关：玩家先发现泥土，再回到蚁穴报信，不需要自己搬泥。
- 报信成功后，第一关养成的 10 只工蚁会赶往泥堆，把泥自动搬到入口。
- 每个入口需要 3 块泥；3 处泥堆各有 2 块泥，正好足够完成防洪。
- 若多只工蚁同时赶到同一入口，入口提前封死后，后续工蚁会带着泥自动改道，不会丢失泥土。
- 倒计时结束后，未封入口开始进水；积水到达蚁穴则失败。
- 三个二维码定位框及其内部区域被视为禁区，玩家和工蚁不能钻进去。
- 扫码模式会暂停限时关卡计时。

### 第 3 关：入侵者

- 守住蚁穴 45 秒。
- 敌对红蚂蚁从二维码边缘的可达入口出现，并沿通道冲向蚁穴。
- Space / 手机「咬」按钮进行近距离攻击。
- 普通敌蚁需要咬 2 次；周期性出现的大型敌蚁需要咬 4 次，并会对蚁穴造成更高伤害。
- 蚁穴生命归零则失败。

### 后续关卡规划

- 第 4 关「狩猎」：解锁 F 蚁酸远程攻击和减速。
- 后续加入食物争夺、敌对蚁群运输线与大迁徙。

## 操作

- 桌面：`WASD` 或方向键
- 手机：页面下方方向键，也可直接在二维码上滑动

## 技术

纯静态前端：HTML + CSS + JavaScript + Canvas。

二维码编码使用 `qrcode-generator`（通过 jsDelivr CDN 加载），因此不需要后端，可以直接部署在 GitHub Pages。

## GitHub Pages

仓库已经按静态站点结构组织，可直接从 `main` 分支根目录发布：

`Settings → Pages → Build and deployment → Deploy from a branch → main / (root)`

部署后的项目地址通常是：

`https://newtv-ai.github.io/qr-ant-colony/`

## 原型目标

第一版刻意不做复杂战斗、建筑树和大量 UI，先验证三个核心体验：

1. 二维码作为蚁穴地图是否有独特感。
2. “发现食物 → 带回信息 → 蚁群自动搬运”的循环是否有满足感。
3. 从一只蚂蚁逐渐变成整张二维码里都有蚂蚁运输线，是否能形成明显的成长反馈。

## 游戏中扫码保护

二维码使用 H 级纠错，并在游戏覆盖层之上增加“扫码安全层”：

- 三个定位框、Timing、Format、Alignment 等二维码关键结构会在每一帧最后重新绘制，游戏元素不会永久遮住这些功能区。
- 非关键深色模块会保留中心黑色采样核心，尽量兼顾游戏画面与二维码识别。
- 食物、泥土、入口等随机点会避开二维码关键结构，并保证位于从蚁穴可达的连通区域。
- 页面通过 jsQR 定期直接解码“当前游戏 Canvas”，并校验解出的内容是否与二维码原始内容完全一致。
- 如果当前游戏画面解码失败，会自动开启更强的二维码保护层并再次检测。
- 页面顶部会显示“✓ 游戏画面可扫码 / 正在增强二维码保护 / 建议用扫码模式”等实时状态。
- 「扫码模式」继续保留作为保险；限时关卡进入扫码模式时会暂停计时。

这意味着项目不再只依赖理论上的 H 级纠错，而是会对玩家当前看到的游戏画面进行实际解码自检。
